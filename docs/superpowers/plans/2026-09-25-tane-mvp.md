# Tane MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `projects/tane/frontend` に、ローカル問題データのみで動く四則演算ステージ制の計算学習アプリ（Next.js製PWA）のMVPを構築する。

**Architecture:** Next.js (App Router) 単体構成。`lib/game/` にUI非依存の純粋関数としてゲームロジック（問題生成・HP管理・ステージ進行・回答入力・進行状況判定）を実装し、Vitestでユニットテストする。UI層（数字キーボード・HPバー・Spruキャラクター・ステージ画面）はSpra-Goの`frontend/`一式を土台に複製し、配色とキャラクターのみTane用に差し替える。バックエンドAPIは持たず、クリア状況のみlocalStorageに保存する。PWA対応は`next-pwa`等の外部パッケージを使わず、`manifest.json` + 自前の`sw.js`で最小構成にする。

**Tech Stack:** Next.js (App Router) / React / TypeScript / Tailwind CSS v4 / shadcn・radix / Vitest

**Spec:** `company/spra/tane/docs/2026-09-25-tane-mvp-design.md`

## Global Constraints

- 1リポジトリ構成。`projects/tane/frontend/` にNext.jsを配置し、リポジトリルートは将来のLaravel追加のために空けておく。
- Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/radix。Spra-Goの`frontend/`一式（`package.json`のバージョン構成、`components.json`、`tsconfig.json`）をベースに複製する。
- 状態管理はReact標準hooks（useState/useReducer）のみ。外部状態管理ライブラリは導入しない。
- データはローカル静的データ（TS）のみ。外部APIは呼ばない。
- PWA対応を最初から組み込む（manifest.json + Service Worker）。
- 画面は横向き固定。ブラウザではOSレベル固定不可のため、縦向き時に案内オーバーレイを表示する形で対応する。
- `lib/game/` はUI非依存の純粋関数として実装する。
- ゲームロジック（`lib/game/`）はVitestでユニットテストする。UIコンポーネントは手動確認のみでよい。
- マスコットはSmartSprouts公式キャラクター「Spru」の簡易2D表現を採用する（3Dモデルは対象外）。
- ドキュメント（本計画書・設計書含む）は日本語で作成する。

## Review Focus

- わり算の出題で割り切れない問題（余りが出る）が生成されると、正解が存在しない詰みの問題になる → Task 4で出題が必ず割り切れることをテストで保証する。
- ひき算の出題で答えが負になると、数字キーボード（0-9のみ）では入力不可能な問題になる → Task 4で全レベルにおいて`operandA >= operandB`をテストで保証する。
- 数字キーボードで4桁を超える入力や空回答での送信ができてしまうと、異常な回答判定につながる → Task 7で上限桁数と空回答防止をロジックとしてテストする。
- 存在しないstageId（URL直打ち等）でステージ画面にアクセスした際にクラッシュする → Task 9で`getStageById`が未知のIDに対して`undefined`を返すことをテストし、Task 14でUI側のフォールバック表示を実装する。
- 最終問題（20問目）を誤答してHPが同時に0になった場合、「ステージクリア」と「HP0で失敗」のどちらが優先されるか仕様上曖昧 → Task 6でfailed判定をcleared判定より先に評価する順序をテストで固定する。

- [ ] **Step 1: 失敗するテストを書く**

`src/lib/game/problem-generator.test.ts`:

```typescript
import { describe, expect, it } from "vitest";

import { generateProblem, generateStageProblems } from "@/lib/game/problem-generator";

describe("generateProblem", () => {
  it("たし算Lv.1は1〜9の数字同士で、答えが正しい", () => {
    const problem = generateProblem("add", 1, () => 0);
    expect(problem.operandA).toBeGreaterThanOrEqual(1);
    expect(problem.operandA).toBeLessThanOrEqual(9);
    expect(problem.operandB).toBeGreaterThanOrEqual(1);
    expect(problem.operandB).toBeLessThanOrEqual(9);
    expect(problem.answer).toBe(problem.operandA + problem.operandB);
  });

  it("ひき算はどのレベルでも答えが負にならない", () => {
    const rngValues = [0, 0.1, 0.5, 0.9, 0.99];
    for (const level of [1, 2, 3]) {
      for (const rngValue of rngValues) {
        const problem = generateProblem("sub", level, () => rngValue);
        expect(problem.operandA).toBeGreaterThanOrEqual(problem.operandB);
        expect(problem.answer).toBe(problem.operandA - problem.operandB);
        expect(problem.answer).toBeGreaterThanOrEqual(0);
      }
    }
  });

  it("わり算はどのレベルでも割り切れる（余りが出ない）", () => {
    const rngValues = [0, 0.1, 0.5, 0.9, 0.99];
```

```typescript
import { applyDamage, INITIAL_HP, isDefeated } from "@/lib/game/hp";
import type { Problem } from "@/lib/game/problem-generator";

export type StageStatus = "in-progress" | "cleared" | "failed";

export interface StageState {
  problems: Problem[];
  currentIndex: number;
  hp: number;
  correctCount: number;
  status: StageStatus;
}

export function createStage(problems: Problem[]): StageState {
  if (problems.length === 0) {
    throw new Error("problems must not be empty");
  }
  return {
    problems,
    currentIndex: 0,
    hp: INITIAL_HP,
    correctCount: 0,
    status: "in-progress",
  };
}

export function currentProblem(state: StageState): Problem {
  return state.problems[state.currentIndex];
}

export function submitAnswer(state: StageState, answer: number): StageState {
  if (state.status !== "in-progress") {
    return state;
  }

  const problem = currentProblem(state);
  const correct = answer === problem.answer;
  const hp = correct ? state.hp : applyDamage(state.hp);
  const correctCount = correct ? state.correctCount + 1 : state.correctCount;
  const nextIndex = state.currentIndex + 1;

  // HPが0になった場合は、全問終了と同時であってもfailedを優先する。
  let status: StageStatus = "in-progress";
  if (isDefeated(hp)) {
    status = "failed";
  } else if (nextIndex >= state.problems.length) {
    status = "cleared";
  }

  return {
    problems: state.problems,
    currentIndex: nextIndex,
    hp,
    correctCount,
    status,
  };
}
```

```typescript
export function appendDigit(current: string, digit: string): string {
```

```typescript
import type { Operator } from "@/lib/game/problem-generator";

export interface StageDefinition {
  id: string;
  operator: Operator;
  level: number;
  title: string;
}

const OPERATOR_LABEL: Record<Operator, string> = {
  add: "たし算",
  sub: "ひき算",
  mul: "かけ算",
  div: "わり算",
};

function buildStages(): StageDefinition[] {
  const operators: Operator[] = ["add", "sub", "mul", "div"];
  const stages: StageDefinition[] = [];
  for (const operator of operators) {
    for (let level = 1; level <= 3; level++) {
      stages.push({
        id: `${operator}-${level}`,
        operator,
        level,
        title: `${OPERATOR_LABEL[operator]} Lv.${level}`,
      });
    }
  }
  return stages;
}

export const STAGES: StageDefinition[] = buildStages();

export function getStageById(id: string): StageDefinition | undefined {
  return STAGES.find((stage) => stage.id === id);
}

export function getNextStage(id: string): StageDefinition | undefined {
  const index = STAGES.findIndex((stage) => stage.id === id);
  if (index === -1 || index === STAGES.length - 1) {
    return undefined;
  }
  return STAGES[index + 1];
}
```

```typescript
const STORAGE_KEY = "tane:cleared-stages";

export function getClearedStageIds(): string[] {
  if (typeof window === "undefined") {
    return [];
  }
  try {
    const raw = window.localStorage.getItem(STORAGE_KEY);
    if (!raw) {
      return [];
    }
    const parsed = JSON.parse(raw) as unknown;
    return Array.isArray(parsed)
      ? parsed.filter((value): value is string => typeof value === "string")
      : [];
  } catch {
    return [];
  }
}

export function markStageCleared(stageId: string): void {
  if (typeof window === "undefined") {
    return;
  }
  const cleared = new Set(getClearedStageIds());
  cleared.add(stageId);
  window.localStorage.setItem(STORAGE_KEY, JSON.stringify([...cleared]));
}
```

```tsx
function operatorSymbol(operator: Operator): string {
  switch (operator) {

      return "+";
    case "sub":
      return "−";

      return "×";
    case "div":

export function StagePlayer({ stageId }: { stageId: string }) {

  const stageDefinition = getStageById(stageId);

  const initialState = useMemo<StageState | null>(() => {
    if (!stageDefinition) {
      return null;
    }
    const problems = generateStageProblems(stageDefinition.operator, stageDefinition.level);
    return createStage(problems);
  }, [stageDefinition]);

  const [state, setState] = useState<StageState | null>(initialState);
```

```javascript
const CACHE_NAME = "tane-cache-v1";
const APP_SHELL = ["/", "/manifest.json", "/icons/icon.svg"];

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(APP_SHELL))
  );
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.filter((key) => key !== CACHE_NAME).map((key) => caches.delete(key))
      )
    )
  );
  self.clients.claim();
});

self.addEventListener("fetch", (event) => {
  if (event.request.method !== "GET") {
    return;
  }
  event.respondWith(
    caches.match(event.request).then((cached) => {
      if (cached) {
        return cached;
      }
      return fetch(event.request)
        .then((response) => {
          const responseClone = response.clone();
          caches.open(CACHE_NAME).then((cache) => cache.put(event.request, responseClone));
          return response;
        })
        .catch(() => cached);
    })
  );
});
```
